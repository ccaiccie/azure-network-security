The source creates Azure infrastructure and an optional ZScaler association. No ZIA account/license, Azure persistent-access grant, secret-value provisioning, partner location/tunnel provisioning, protected hub route activation, category/rule activation or schema-specific log exporter is implemented. Those are operator prerequisites requiring current vendor support and authorization. Missing them is BLOCKED, not permission to fabricate payloads or substitute Azure Firewall/NVA.

A successful HTTP marker, Block-like page, connected TCP, tunnel counter, SPP status or mock test establishes only its own observation. Provider-native transaction correlation and actual origin/route/tunnel evidence are needed for end-to-end conclusions. No universal fail-open/fail-closed or session-continuity claim is supported.
